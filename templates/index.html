ABOUT THE TOOL

It is an experimental tool that uses a modified version of the solution to the Knapsack Problem. The tool features a Hybrid Knapsack solution that uses Genetic Algorithm (GA) and Branch-and-Bound (B&B) to deliver optimized budgeting results.

Additionally, the tool features a comparison of the following versions of the Knapsack Algorithm:

Knapsack Algorithm w Branch-
and-Bound

Time: O(2^n) worst case
Space: O(2^n) worst case

Hybrid Knapsack
(GA + B&B)

Time: O(g·p·n + 2^n) worst case
Space: O(p·n + 2^n) worst case
